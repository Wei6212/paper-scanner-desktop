# 纸页扫描：电脑端实现与验证

日期：2026-10-26。

## 已实现

- macOS 原生桌面窗口，选择目录、添加图片、拖入文件、可选递归子目录。
- 检测模型自动框选四角，支持手动拖动、重置框选和旋转。
- 四点透视校正；内嵌增强模型、去光照、Gamma 与对比度调整，保留彩色。
- 可选两阶段曲面展平，检查位移范围及局部网格折叠；异常时保留原校正结果并提示。
- 原始尺寸、70%、50%、自定义比例、自定义宽高。
- JPEG/PNG 导出；按实际字节数限制单文件大小，JPEG 优先调整质量，必要时等比例缩图。
- 顺序后台队列、停止操作、损坏文件隔离、自动编号、不覆盖源文件、CSV 处理记录。

## 从小米调用链迁移的部分

使用 APK 内提取的 `document_detect.mnn`、`document_enhance.mnn`、`document_dewarp.mnn`、`document_dewarp_stage2.mnn`，通过 MNN Module API 在桌面执行。

检测输入为 384×384 RGB，输出两通道边缘/区域预测。增强输入为 512×512 RGB，输出经尺寸恢复用于逐通道光照归一化。

曲面第一阶段输入为 193×193，输出为 385×385 两通道位移；第二阶段输入为第一次采样后的 385×385 图像，输出细化位移，以 0.2 权重加入网格。模型输入张量、输出形状和真实样本推理均已检查。

桌面端重新实现几何候选筛选、输出尺寸计算、缩放和部分图像后处理。APK 内部的自动曲面触发状态没有照搬，改为用户可选开关。未宣称逐像素复刻 Android SDK。

本轮进一步确认了 JNI 图像转换辅助函数保持 RGB 顺序；检测分支随后有颜色通道转换。当前桌面前处理已用用户的手绘样本验证，但尚未逐阶段比对手机中间结果。

## 验证

### 自动测试

`tests/` 覆盖：

- 100%、70%、50%、自定义宽高的实际像素计算与比例保持。
- JPEG/PNG 在 0.03 MB、0.2 MB、2 MB 上限下编码，检查真实字节数并重新解码。
- 不覆盖源文件和既有同名结果。
- 无效尺寸与无效体积输入。
- 四角透视变换的尺寸与彩色像素保留。
- 非法框选坐标拒绝。
- EXIF 方向与透明背景处理。
- 曲面恒等网格重映射。
- 真实内嵌模型对用户手绘图的纸底与彩色输出。

21 项测试通过（包含纸边背景清除、边缘黑字/彩色保留与无纸边时不修改的检查）。

## 交付与限制

`dist/纸页扫描.app` 为 macOS Apple Silicon 应用，包含运行时和模型。打包应用已独立运行真实模型、曲面处理及批量导出，测试输出为 832×564、199,580 字节，符合 0.2 MB 上限；通过 codesign 完整性检查。设置区和弹出菜单使用明确的浅色配色，避免系统深色模式影响可读性。Windows 与 Intel Mac 尚未打包验证。

当前读取 TIFF 第一页，不提供 PDF 导出。输入边长最多 30000 像素，总像素最多 8000 万，避免超大图耗尽内存。导出过程会重新编码图像，不保留原始照片的 EXIF、定位等元数据。

曲面开关对平整手绘图可能产生额外变形，默认关闭。强光反射、严重污渍、失焦或被遮挡文字的恢复尚无保证。当前测试样本来自用户提供的这一张原图及自动生成的边界测试图，未完成大规模不同纸张数据集验收。

## 纸面铺满修正

新增 `edges.py`，在透视校正和彩色增强后对边缘窄带进行精修，清除误带入的桌面背景；使用边界过渡置信度、平滑曲线及黑色/高饱和笔迹保护，不改变内容坐标与输出像素。默认启用，可在设置中关闭。结果画布不再添加 24 像素内边距，仍保持图片比例，不裁切内容来填满预览。样例见 `artifacts/纸面铺满效果.jpg`。
