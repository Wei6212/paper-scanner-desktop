# 命令行使用说明

命令行模式直接调用本地扫描引擎，不创建 Qt 窗口，不读取界面中保存的参数。适用于批量转换、自动整理图片及智能体调用。

## 快速开始

### Windows 便携版

先完整解压程序，在程序目录打开 CMD：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" -s 90 -e 50
```

该命令自动识别纸张、透视校正，以 50% 强度增强，按校正后宽高的 90% 导出 JPEG。结果和 CSV 处理记录保存到 `E:\output`，处理结束后退出。

便携包包含两个入口，共用 `app`、`runtime` 目录，不能单独复制 exe：

| 入口 | 行为 |
| --- | --- |
| `纸页扫描.exe` | 不带参数打开界面；带处理参数进入命令行模式 |
| `纸页扫描-cli.exe` | 控制台入口，方便等待完成和捕获输出；不带参数显示帮助 |

自动化优先使用 `纸页扫描-cli.exe`。如果使用原来的 GUI 入口，在 CMD 中显式等待：

```bat
start "" /b /wait "纸页扫描.exe" -i "D:\photo" -o "E:\output" -s 90 -e 50
```

PowerShell 调用示例：

```powershell
& ".\纸页扫描-cli.exe" -i "D:\photo" -o "E:\output" -s 90 -e 50
$LASTEXITCODE
```

### 源码运行

在已安装项目依赖的 Python 环境中，从项目根目录执行：

```bash
python main.py -i ./samples -o ./artifacts/命令行结果 -s 90 -e 50
python main.py --help
```

也可以使用 `python -m paper_scanner.cli`。源码的 `python main.py` 不带参数仍打开桌面界面。

## 参数

| 参数 | 含义 | 默认值及范围 |
| --- | --- | --- |
| `-i`, `--input PATH ...` | 输入图片或目录；可给多个路径，也可重复 `-i` | 处理时必填 |
| `-o`, `--output DIR` | 输出目录，不存在时自动创建 | 处理时必填 |
| `-s`, `--scale PERCENT` | 校正后图片的宽高缩放百分比 | 100；范围 1～200 |
| `-e`, `--enhance PERCENT` | 彩色增强强度；0 表示关闭增强和相关模型加载 | 100；范围 0～100 |
| `--black-white` | 启用黑白文字模式，彩色内容也会转黑白 | 默认关闭 |
| `--black-threshold N` | 灰度低于阈值转黑，其余转白；仅黑白模式生效 | 180；整数 1～255 |
| `--stroke-radius PIXELS` | 黑色笔画向外加粗的半径；0 只做二值化，仅黑白模式生效 | 1；整数 0～3 |
| `-r`, `--recursive` | 包含输入目录的子目录 | 默认只处理当前层 |
| `--width PIXELS` | 输出最大宽度，等比例缩放 | 未设置；0～30000 |
| `--height PIXELS` | 输出最大高度，等比例缩放 | 未设置；0～30000 |
| `--format JPEG\|JPG\|PNG` | 输出格式，不区分大小写 | JPEG |
| `--quality N` | JPEG 起始质量，PNG 不使用此值 | 95；范围 60～100 |
| `--max-mb MB` | 单张文件大小上限，1 MB = 1,000,000 字节 | 不限制；范围 0.01～1000 |
| `--no-crop` | 关闭纸张检测与透视裁剪 | 默认启用检测与裁剪 |
| `--no-fill-frame` | 关闭纸边精修 | 默认启用，仅裁剪和增强均开启时生效 |
| `--dewarp` | 开启曲面展平 | 默认关闭 |
| `--rotate 0\|90\|180\|270` | 在处理前顺时针旋转 | 0 |
| `--json` | stdout 仅输出一份 JSON；进度与模型诊断写入 stderr | 默认输出文本进度和汇总到 stderr |
| `--quiet` | 隐藏逐张进度和提示，保留错误、汇总及模型诊断 | 默认显示逐张进度 |
| `--no-csv` | 关闭 CSV 处理记录 | 默认生成 CSV |
| `-h`, `--help` | 查看帮助并退出 | 不要求输入和输出参数 |

尺寸规则：

- `--width` / `--height` 不能与 `-s` 同时使用。
- 只填一个尺寸时，按该边等比例缩放；同时填写时，图片完整适配最大宽高，不拉伸、不补边。
- 使用自定义尺寸时，宽高至少一个大于 0；可以放大，但输出不能超过 8000 万像素。
- `--max-mb` 会在需要时降低 JPEG 质量，质量最低为 60；仍超限时继续缩图。PNG 超限时直接缩图，因此实际尺寸可能小于指定值。
- `-e 0` 仅关闭增强，仍会执行默认的纸张检测；单纯转格式或缩放请同时添加 `--no-crop -e 0`。
- `--black-white` 独立于 `-e`：先执行校正、可选展平和增强，再转黑白；`-e 0` 不会关闭黑白处理。需要按原图灰度处理时使用 `--no-crop -e 0`，不启用展平。
- 黑白模式按 RGB 亮度转灰度，例如阈值 180 时灰度 125 转黑、180 和 255 转白。提高阈值可以保留更淡的笔画，也会带入更多背景和噪点。
- 加粗在校正后的完整分辨率上执行，导出缩图时效果随之缩小。它可以连接很小的断点，但不能可靠恢复完全缺失的笔画；加粗过大会让笔画粘连。
- 黑白模式建议使用 PNG：导出缩放和体积限制缩图后重新二值化，保存为 1 位黑白图像。JPEG 压缩会产生灰度，不保证只有 0 和 255。

## 常用操作

递归扫描、输出 PNG，并限制单张体积：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" -r --format png --max-mb 2
```

处理多个输入，限制输出最大宽高：

```bat
纸页扫描-cli.exe -i "D:\photo\第一页.jpg" "D:\photo\第二页.png" -i "D:\补充图片" -o "E:\output" --width 1600 --height 2000
```

只转换格式和缩放，不检测纸张、不增强：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" --no-crop -e 0 -s 50 --format png
```

开启曲面展平，并在处理前顺时针旋转：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" --dewarp --rotate 90
```

将淡字转黑，并轻微加粗笔画，直接按原图灰度判断：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" --no-crop -e 0 --black-white --black-threshold 180 --stroke-radius 1 --format PNG
```

如需同时去阴影与校正，去掉 `--no-crop -e 0`。只做黑白阈值转换、不加粗时设为 `--stroke-radius 0`。这三个黑白参数不改变 JSON 字段和退出码约定。

## 智能体和脚本调用

### 从 stdout 获取 JSON

CMD 中分别保存结构化结果和诊断：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" -s 90 -e 50 --json --quiet > result.json 2> processing.log
echo %ERRORLEVEL%
```

输出采用 UTF-8。`--quiet` 不保证 stderr 为空：模型库可能输出初始化诊断。不要将 stderr 合并到 stdout，否则结果将不再是纯 JSON。

JSON 顶层字段：

| 字段 | 类型及含义 |
| --- | --- |
| `schema_version` | 整数，当前为 1 |
| `status` | `success`、`partial_failure`、`failed`、`error` 或 `cancelled` |
| `exit_code` | 与进程退出码一致 |
| `total` | 本次发现并去重后的图片总数；输入校验失败时为 0 |
| `succeeded` / `failed` | 已完成导出数、已处理失败数 |
| `files` | 按处理顺序列出每张已处理图片的结果 |
| `record` | CSV 的绝对路径；关闭 CSV 或未能生成时为 `null` |
| `error` | 批次级错误或中断原因；正常完成时为 `null`。单张错误在 `files` 中 |

`files` 中每项都有 `input`（绝对路径）和 `status`（`success` / `failed`）。成功项另有 `output`、`width`、`height`、`bytes`、`quality`、`resized_for_limit`、`warning`、`seconds`；失败项另有 `error`。`quality` 在 PNG 输出时为 `null`，`seconds` 是引擎处理耗时，不含编码和写盘。未检测到明确纸边等降级情况写入 `warning`，仍可成功导出。

中断时，尚未处理和正在处理但未导出的图片不加入 `files`，所以 `succeeded + failed` 可能小于 `total`。CSV 写入失败会导致退出码 1，即使图片均已导出。

### Python 调用示例

在便携包目录保存并运行以下脚本，按本机情况修改三个路径：

```python
import json
from pathlib import Path
import subprocess

executable = Path.cwd() / '纸页扫描-cli.exe'
result = subprocess.run(
    [str(executable), '-i', r'D:\photo', '-o', r'E:\output',
     '-s', '90', '-e', '50', '--json', '--quiet'],
    capture_output=True,
    text=True,
    encoding='utf-8',
    timeout=600,
)
try:
    report = json.loads(result.stdout)
except json.JSONDecodeError as error:
    raise RuntimeError(f'程序未返回 JSON，退出码 {result.returncode}：{result.stderr}') from error

for item in report['files']:
    if item['status'] == 'success':
        print('已生成：', item['output'])
    else:
        print('处理失败：', item['input'], item['error'])

if result.returncode != 0:
    raise SystemExit(f'批次未完全成功：退出码 {result.returncode}，原因 {report["error"] or report["status"]}')
```

参数使用列表传递，路径不需要额外拼接引号，也不需要 `shell=True`。Python 的 `subprocess.run` 等待进程结束；超时会终止进程，不能保证当前图片完成或 CSV 落盘。

### 退出码

| 退出码 | 含义 | 调用方处理 |
| --- | --- | --- |
| 0 | 所有图片导出成功，或正常显示帮助 | 使用结果 |
| 1 | 至少一张处理失败、CSV 写入失败或运行异常 | 检查 `files`、`error` 和 stderr，已成功结果保留 |
| 2 | 参数错误、输入不存在、没有支持的图片、输入输出位置冲突 | 修改参数或输入后重试 |
| 130 | 用户通过 Ctrl+C 中断 | 已完成结果保留，可重新发起处理 |

上述 JSON 协议在 Python 入口正常启动后生效。若运行时或程序文件缺失，Windows 启动器直接向 stderr 报错并返回 1，不弹窗，也不保证生成 JSON。

## 文件处理规则与限制

- 支持 JPEG、PNG、BMP、TIFF、WebP 输入，TIFF 只读取第一页；不支持 PDF 输入或导出。
- 目录中的不支持格式、名称以 `.` 开头的文件和目录跳过；明确指定不支持的文件则返回输入错误。递归扫描不跟随目录符号链接。
- 按解析符号链接后的绝对路径去重；目录项按名称排序，多组输入按参数顺序处理。先固定输入列表，再逐张顺序处理。
- 输出目录不能与输入目录相同，也不能包含明确指定的输入文件或目录。允许把输出目录放在输入目录下面，扫描时自动排除整个输出目录。
- 多级输入统一导出到一个输出目录，不复制子目录结构；同名结果使用 `_扫描`、`_扫描_2` 等后缀，原图和既有文件均不覆盖。
- 损坏图片报错后继续处理后续图片；再次执行会重新处理输入，不自动跳过上次成功的图片。
- 输入边长最多 30000 像素、总像素最多 8000 万；重新编码不保留原图 EXIF、定位等元数据。
- 命令行参数独立于界面设置：默认缩放 100%、增强 100%、JPEG 质量 95、不限制文件大小，默认关闭曲面展平和黑白模式。
