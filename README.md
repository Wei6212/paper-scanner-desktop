# 纸页扫描

本地桌面应用。选择图片目录后，自动检测纸边、校正透视、去阴影并增强彩色内容，批量导出到指定位置。提供可选的两阶段曲面展平。

## 启动

GitHub 仓库包含源码、四份运行模型、测试样例及文档。`dist/` 中的应用和便携包需要本地构建，不随源码提交；首次克隆后请按下方“从源码运行”启动。

在当前 Mac 上双击 `dist/纸页扫描.app`，或双击项目根目录的 `启动纸页扫描.command`。应用已经包含 Python 运行时、图像处理库和四份本地模型，无需安装 Python，也不需要上传照片。

Windows 64 位便携版位于 `dist/纸页扫描-Windows-x64.zip`。将整个压缩包解压后双击“纸页扫描.exe”，无需安装 Python。请保留 `app`、`runtime` 文件夹，不能单独复制 exe。适用 Windows 10 1903 及更新版本、Windows 11。

Windows 包已核查二进制架构、依赖和资源；当前构建主机为 Mac，尚未进行原生 Windows 运行验收。包内提供“运行自检.cmd”和启动日志。构建方式见 [Windows打包说明](docs/Windows打包说明.md)。Intel Mac 尚未生成安装包。

## 使用

点击主窗口右上角“关于”，可查看软件名称“纸页扫描”、版本 `0.1.0`、作者“影子”及版权信息“© 2026 影子。保留所有权利。”。

1. 点击“选择目录”，也可以添加图片或拖入文件夹。勾选“包含子目录”可以递归扫描；输出目录会从当前导入列表中排除。
2. 选择队列中的图片，自动生成原图和扫描结果对照。每次拖动任意一个角点并松开鼠标后，自动更新预览；也可以旋转图片或重新自动框选。
3. 调整导出分辨率、文件上限和输出目录，点击“批量导出全部图片”。

队列中每张图片右侧提供“移除”按钮，可以单独移除图片；“清空”仍可清空整个队列。移除仅影响当前队列，保留原文件和已导出结果。预览或导出处理期间暂时禁用移除。

勾选队列下方的“显示缩略图”，可在图片名前显示 40×40 的原图缩略图，保持图片比例和 EXIF 方向。首次使用默认关闭，并记住上次选择。开启后仅在后台按需读取当前可见图片，每次处理一张，最多缓存 128 张小图；关闭后释放缩略图缓存，不再读取后续图片。损坏图片显示占位，不影响其他图片。

JPEG、PNG、BMP、TIFF、WebP 可作为输入。多页 TIFF 当前只读取第一页。

### 画布缩放

原图与扫描结果两侧都支持独立缩放和平移，方便检查纸边识别、文字和增强细节：

- 鼠标移到对应画布上，直接滚动滚轮即可连续平滑缩放，无需按住 Ctrl；以鼠标所在位置为中心放大或缩小，也支持触控板精细滚动。还可以点击「−」「+」。
- 放大后按住鼠标左键或中键拖动，查看不同区域。左侧角点优先用于调整框选。
- 左侧「微调」栏可定位四角；也可直接点击角点选中。方向键每次移动 1 个原图像素，Shift + 方向键每次移动 10 像素，松开后自动更新预览。
- 点击「100%」按原始像素查看，点击「适应」或双击画布恢复全图显示。
- 预览保留完整分辨率；微调框选后，两侧均保留缩放比例和查看位置，切换图片或旋转后恢复全图。

画布缩放仅改变查看方式，不影响导出尺寸。

### 分辨率设置

| 选项 | 行为 |
| --- | --- |
| 原始 · 100% | 保留透视校正后的完整像素 |
| 70% | 宽、高各乘 0.7 |
| 50% | 宽、高各乘 0.5 |
| 自定义比例 | 输入 1% 到 200% |
| 自定义宽高 | 只填一边自动计算另一边；同时填入表示最大宽高范围，保持比例 |

例如，校正图为 4000×3000，70% 导出为 2800×2100；自定义宽高 1000×600，得到 800×600，不会将纸张拉伸。

“原始”指完整的校正图尺寸，不是保留原始照片中的桌面或背景，也不代表复制原始 JPEG 字节。

### 文件体积上限

勾选“限制单张文件大小”，输入 2 MB 或其他数值。每次编码后检查实际文件字节数，成功结果不超过设置值。

- JPEG：先尝试指定质量，再在 60 到指定质量之间搜索；仍超限时等比例缩图。
- PNG：保持无损编码，超限时等比例缩图。
- 1 MB 按 1,000,000 字节计算。
- 分辨率和体积限制可以同时设置；若二者不能同时满足，优先满足体积上限，因此最终像素可能低于所选分辨率。

最终尺寸和文件大小显示在队列中，输出目录另保存 CSV 处理记录。

### 内容与几何处理

默认启用纸边检测、透视校正、保色增强及“纸面铺满图片”。纸面铺满会精修框选区域中残留的背景细边，保留内容坐标和像素尺寸；处理全幅照片或特殊纸张时可关闭。结果预览取消了额外内边距，按原比例使用可用宽度。增强强度可降低，以保留浅色笔迹；拖动时自动更新预览，无需松开鼠标或点击“更新预览”。计算期间可继续拖动，当前计算完成后按最新强度继续刷新。

“曲面展平”适合弯曲纸张，使用两个内嵌模型生成位移场，包含局部折叠检查。平整文档建议关闭；它可能改变原有手绘曲线，无法恢复已被污渍、遮挡或过曝破坏的信息。

源图片和已有结果均不会覆盖。同名结果自动使用序号。单张图片损坏时继续处理后续图片。停止操作在当前计算阶段结束后生效，已导出的结果保留。

## 与小米 APK 的对应

复用从用户提供的 APK 提取出的四份模型，通过桌面 MNN 运行。基本处理顺序为：

```text
本地读图与 EXIF 方向校正
→ 边缘/区域模型
→ 四角几何后处理与透视变换
→ 可选的两阶段曲面展平
→ 增强模型预测校正图
→ 逐通道去光照归一化
→ Gamma 与对比度调整
→ 尺寸与体积控制
→ 保存
```

桌面端重新实现了四角候选筛选、尺寸计算、部分缩放和对比度后处理，并提供手动曲面开关。它不是 Android SDK 的逐像素移植，尚未完成同一原图在手机与桌面各中间阶段的逐像素对照。

详细 APK 分析见 [APK扫描增强实现分析](docs/APK扫描增强实现分析.md)，当前应用实现与验证见 [电脑端实现与验证](docs/电脑端实现与验证.md)。

## 从源码运行

需要 Python 3.11 或 3.12，推荐使用已安装的 uv：

```bash
uv sync --frozen --group dev
uv run main.py
```

也可以直接使用本项目已准备的环境：

```bash
.venv/bin/python main.py
```

运行测试和打包：

```bash
.venv/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen .venv/bin/python scripts/smoke_ui.py
QT_QPA_PLATFORM=offscreen .venv/bin/python scripts/build_app.py
```

## 目录

- `paper_scanner/engine.py`：模型运行、检测、校正、增强。
- `paper_scanner/exporting.py`：分辨率、文件限制与保存。
- `paper_scanner/jobs.py`：后台队列、取消、错误隔离。
- `paper_scanner/ui.py`：原生 Qt 桌面界面。
- `models/`：应用内使用的四份模型。
- `artifacts/`：本地生成的真实样本输出及界面验证截图，不随源码提交。
- `analysis/`：本地 APK 静态分析原始证据，与原始 `base.apk` 一同排除于源码仓库；分析文档中的相关路径用于定位本地材料。
