# 纸页扫描

本地文档扫描工具，图片处理在本机完成，无需上传照片。

## 功能

- 批量导入图片、文件夹，支持拖入和子目录扫描。
- 自动识别纸张边缘、透视校正，支持手动调整四角和旋转。
- 去阴影、保色增强、纸边精修，可调节增强强度。
- 可选曲面展平，处理弯曲纸张。
- 原图与扫描结果对照预览，支持缩放、平移和逐像素微调。
- 图片队列管理与可选缩略图。
- 自定义导出比例、宽高、JPEG／PNG 格式及单张文件大小上限。
- 批量导出与 CSV 处理记录，损坏图片自动跳过，保留原图。
- 支持 JPEG、PNG、BMP、TIFF、WebP 图片输入。
- 支持无界面命令行批处理、JSON 结果和退出码，便于脚本及智能体调用。

## 命令行使用

Windows 便携版完整解压后，在终端执行：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" -s 90 -e 50
```

`-s 90` 表示按校正后尺寸的 90% 导出，`-e 50` 表示增强强度 50%。带处理参数时不显示界面，完成后退出；双击原来的“纸页扫描.exe”仍打开界面。

智能体调用可添加 `--json --quiet`，从 stdout 读取 JSON，并根据退出码判断成功或失败。源码运行使用 `python main.py` 加相同参数。

完整参数、批处理规则和脚本示例见[命令行使用说明](docs/命令行使用说明.md)；Windows 构建见[Windows 打包说明](docs/Windows打包说明.md)。
