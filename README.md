# 纸页扫描

本地文档扫描工具，图片处理在本机完成，无需上传照片。

## 功能

- 批量导入图片、文件夹，支持拖入和子目录扫描。
- “添加图片”记住上次选图的文件夹，清空队列或重启后仍保留；只导入选中的图片。
- 自动识别纸张边缘、透视校正，支持手动调整四角和旋转。
- 去阴影、保色增强、纸边精修，可调节增强强度。
- 可选黑白文字模式：按灰度阈值将淡字转黑，并按像素半径加粗笔画。
- 可选曲面展平，处理弯曲纸张。
- 原图与扫描结果对照预览，支持缩放、平移和逐像素微调。
- 图片队列管理与可选缩略图。
- 自定义导出比例、宽高、JPEG／PNG 格式及单张文件大小上限。
- 可选文字水印：倾斜重复排列，默认灰色半透明，支持自定义文字、颜色和字号。
- 右侧设置栏默认加宽，最小宽度按完整控件计算，缩小窗口时仍可完整显示设置项。
- 批量导出与 CSV 处理记录，损坏图片自动跳过，保留原图。
- 支持 JPEG、PNG、BMP、TIFF、WebP 图片输入。
- 支持无界面命令行批处理、JSON 结果和退出码，便于脚本及智能体调用。

## 命令行使用

Windows 便携版完整解压后，在终端执行：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" -s 90 -e 50
```

`-s 90` 表示按校正后尺寸的 90% 导出，`-e 50` 表示增强强度 50%。带处理参数时不显示界面，完成后退出；双击原来的“纸页扫描.exe”仍打开界面。

智能体调用可添加 `--json --quiet`，从 stdout 读取 JSON，并根据退出码判断成功或失败。源码运行使用 `python main.py` 加相同参数。

完整参数、批处理规则和脚本示例见[命令行使用说明](docs/命令行使用说明.md)；Windows 构建见[Windows 打包说明](docs/Windows打包说明.md)。

## 淡字与笔画加强

“黑白文字”模式开关每次启动默认关闭。勾选或取消勾选后自动更新当前图片预览；预览计算中也可以切换，完成后按最新状态刷新。先使用黑白阈值 `180`、加粗半径 `1 px`，放大检查文字；修改阈值或半径后点击“更新预览”。灰度低于阈值转纯黑，其余转纯白；例如灰度 `125` 会变黑，`255` 保持白色。阈值越高，越淡的笔画也会被保留，但灰色背景和杂点也更容易变黑。

加粗半径范围为 `0～3 px`，`0` 只做二值化，`1` 向周围扩展约一个像素，可连接很小的断点；过大会导致笔画粘连，无法可靠恢复完全缺失的笔画。半径作用于校正后的完整分辨率，导出缩小时效果也会随之缩小。彩色印章、照片等同样会转黑白，适合白纸黑字原稿。

黑白转换在去阴影和彩色增强之后执行；需要直接按原图灰度判断时，关闭“去阴影与彩色增强”。纯黑白请选 PNG，不添加水印时，缩放及体积限制缩图后仍只含黑白两色；JPEG 压缩会重新产生灰度。

命令行示例（保留整图、直接按原图灰度处理）：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" --no-crop -e 0 --black-white --black-threshold 180 --stroke-radius 1 --format PNG
```

## 文字水印

在右侧“文字水印”中勾选“导出时添加文字水印”，输入文字，再按需选择颜色和字体大小。默认颜色为灰色 `#808080`，透明度固定为 50%，字号为 `36 px`，倾斜 45° 重复排列。文字最多 100 个字符，字号支持 `8～300 px`；小图或长文字会自动缩小字号以容纳完整文字。

水印仅添加到最终导出的 JPEG／PNG，扫描预览不显示，原图保持不变。字号按导出分辨率计算，因文件体积限制继续缩图时，水印随图片缩小。黑白模式下也会保留水印的颜色和半透明效果，因此添加水印后不再是纯黑白图像。文字、颜色和字号会记住，每次启动默认关闭水印，避免误加上次用途的文字。

水印使用本机中文字体，无需联网；Windows 优先使用微软雅黑，macOS 使用系统中文字体，Linux 需安装 Noto Sans CJK 或文泉驿正黑。找不到可用字体时会明确报错。

命令行同样支持：

```bat
纸页扫描-cli.exe -i "D:\photo" -o "E:\output" --watermark "仅供测试专用" --watermark-color "#808080" --watermark-size 36
```
